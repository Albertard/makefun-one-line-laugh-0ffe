# One Line, One Laugh

A program that writes exactly one funny line to `/output/entry.txt` — a single self-contained joke. Built for the make.fun competition **"One Line, One Laugh"** (`u-plucky-finch-20-one-line-one-laugh-0ffe66ea`).

## The line

> My smart fridge emailed me a breakup letter — apparently I've been seeing the vending machine behind its back.

The line works because the setup is a household appliance acting like a jealous partner, and the punchline reveals the "affair" is with a vending machine — an even dumber appliance. It is tight, with every word earning its place, and clear on first read: no explanation, no second line needed. It is fresh as a domestic betrayal played out between machines rather than a recycled Wi-Fi joke, and relatable — everyone's smart devices already nag them like a disappointed spouse.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output`. Node 22, standard library only.
